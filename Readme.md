# Multi-Tab Image Downloader Chrome Extension

## Installation Instructions

1. **Download or Clone the Repository**
    - Download this repository as a ZIP file and extract it, or clone it using:
      ```
      git clone https://github.com/your-username/multi-tab-image-downloader.git
      ```

2. **Open Chrome Extensions Page**
    - Go to `chrome://extensions/` in your Chrome browser.

3. **Enable Developer Mode**
    - Toggle the **Developer mode** switch in the top right corner.

4. **Load Unpacked Extension**
    - Click the **Load unpacked** button.
    - Select the extracted project folder (`multi-tab-image-downloader`).

5. **Use the Extension**
    - The extension icon should now appear in your Chrome toolbar.
    - Click the icon to start downloading images from multiple tabs.

---

**Note:**  
This extension is not published on the Chrome Web Store. You must load it manually as described above.
